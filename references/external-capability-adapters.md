# Optional External Capability Adapters

The final-polish workflow remains usable when external skills/tools are unavailable. They are optional adapters, not required dependencies.

| Capability | Role in final-polish | Default |
|---|---|---|
| Presentation runtime / renderer | create, open, render, and technically audit PPTX | use when available |
| `frontend-slides` / `guizang-ppt-skill` | explore a 3-page visual direction before an authorized restyle | off |
| taste / `impeccable` reviewer | second visual opinion after internal visual lint | off |
| Image generation | fill an approved conceptual-asset gap | only with user approval |

Internal rules for alignment, whitespace, hierarchy, cropping, anti-card repetition, contrast, and full-size review still apply without any adapter. Do not claim that an unavailable adapter prevented ordinary QA.
