# Anonymous Final-Polish Regression Case

This private regression specification contains no client content or assets.

## Scenario

- An editable deck has 40+ pages.
- The user has manually changed text and several image crops.
- Feedback says: wording sounds internal, chapter order is unclear, layouts repeat, dark pages lack contrast, images do not match claims, and “next step” appears too early or repeatedly.

## Required behavior

1. Preserve declared manual copy, image positions/crops, and brand elements.
2. Produce a story map that reorders strategy, project cadence, mechanism, and next-stage action by causal logic.
3. Ensure a dark mechanism page differentiates three information layers in a full-size render.
4. Produce revised PPTX, mapped script, technical QA, visual QA scope, commercial QA, and a protection conclusion.
5. The technical report must not be described as visual or commercial acceptance.

## Regression evidence

Run this scenario plus two materially different project types before calling the workflow generally proven. Record failures as rule improvements, not client content.
